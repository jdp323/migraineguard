# Package map (v1)

- `di` — `AppContainer` composition root
- `core/ai` — providers + `FallbackAiClient`
- `core/data/db` — Room database / DAOs / entities
- `core/data/prefs` — DataStore user settings
- `core/design` — theme + typography
- `core/domain` — shared models
- `core/ui` — SectionCard, EmptyState, ProgressRing
- `feature/*` — screens + repositories per domain
- `navigation` — bottom bar NavHost
