Help & data controls

Last updated: October 20, 2026 · Applies to Android v1.8.0 and this website

A few clear steps to get your account, backup and health readings connected.

Install and update

Open the public latest-release page, expand Assets and download the Standard .apk. No GitHub invitation is needed. Update the same package/certificate without uninstalling to keep local data. Preview installs as a separate app with separate records and permissions. The latest verified build is v1.8.0, version code 15. Check Settings → About after installing.

APK files are hosted on public GitHub Releases; this free Firebase site hosts information and policies. Do not uninstall an old app with records just to resolve a signing conflict; try Preview or verify a recovery backup first.

Checked setup

Welcome, Account, Health, AI and Profile show distinct results. Health Connect availability and read grants do not automatically check received steps, heart or sleep. Real received records get their own checks. Optional skips stay marked Skipped in the final review. A successful Gemini or first manual Drive test stays visible until Continue. Skipping AI verification keeps saved keys; remove them in Settings to stop using them.

Restore your account

  1. Choose your Google account. Each account keeps its own profile and local records.
  2. Choose whether to allow private Drive app-data backup. On a returning account, the app checks for an existing backup before profile setup.
  3. Confirm your details and keys once if no completed backup exists.
  4. Use Settings → Back up now and wait for a completed save before switching devices or accounts.
  5. Review Health Connect permission on each phone. Google backup permission does not grant health access.

Google audience access is now External / In production. Every user still grants their own app-data permission. Custom branding is not claimed to be verified. If an account is still blocked, check the installed published APK, any unintended client override and organization/Advanced Protection policy; see the full troubleshooting guide.

Steps, heart rate or sleep missing?

  1. In Health Connect itself, open Data and access and verify actual dated records are present, rather than only a permission switch.
  2. Allow MigraineGuard to read the relevant record types. Standard and Preview have separate permission grants.
  3. In Fitness, choose Samsung Health or Combined Health Connect, then refresh. Source totals are alternatives, not added together.
  4. Heart rate shows the latest available sample, not live watch BPM. Sleep requires completed sessions. Sharing from source apps can be delayed.
  5. If actual records are still missing, expand connection details and use Copy sync report. Share the report privately with the developer; review its timestamps and source metadata before sending it. Never send API keys or a complete journal as a first troubleshooting step.

Remove data or disconnect

Pause backup before removing the cloud snapshot. Use Drive Settings → Manage apps → MigraineGuard → Options → Delete hidden app data, if available, then revoke MigraineGuard's authorization through your Google account. Clear the installed app's storage separately for local data. Signing out or uninstalling alone does not delete Drive data; revoking access alone may not delete the snapshot.

Journal merges can restore locally deleted entries from an old snapshot. Follow the privacy policy's deletion instructions for each copy. Rotate AI keys at the provider to invalidate them. Permissioned source records stay under the control of Health Connect and their source apps.

Contact

Use the developer support email shown on MigraineGuard's Google authorization screen. Include your app version, Android version and a brief description. Avoid sending medical records, passwords or keys. This project does not provide clinical care or emergency support.
