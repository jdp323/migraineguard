# Third-party anatomical artwork

MigraineGuard adapts the anatomical SVG path data and body outlines from [react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter/tree/8ed39ac2ae9cb46fb79d77eedec7e5b029a75174), copyright ELABBASSI Hicham, under the MIT license below. Extracted vector data is bundled as four native JSON resources. The React Native runtime/component code is not included. Local changes provide Android Canvas rendering, app colors, coordinate/hit testing, training-group mapping and controls.

The same notice is included inside the APK at assets/licenses/body-highlighter-MIT.txt.
